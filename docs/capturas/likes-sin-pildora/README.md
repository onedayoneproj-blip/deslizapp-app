# Cifra sin pastilla: capturas reales

Chromium, build de producción local, demo con fixtures separados, 360/390/430 px y temas claro/oscuro. En 390 hay cero, uno sobre foto blanca, dos sobre foto negra y diez dígitos. El corazón conserva su geometría; la cifra no tiene fondo ni contenedor visible. Los números largos pueden envolver sin recorte. No son capturas de Safari ni de una tienda real.

Generadas con `URL=http://localhost:3345 CAPTURAS=/tmp/likes-sin-pildora-final node scripts/probar-catalogo-pulido.mjs`. La prueba valida las seis cantidades en los seis contextos; esta carpeta conserva una selección de las capturas.
