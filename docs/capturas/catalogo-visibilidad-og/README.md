# Evidencias del seguimiento del catálogo

Capturas reales de Chromium sobre build de producción local, con fixtures DEMO independientes. `panel-*`: 360/390/430, claro/oscuro. `visibilidad-*`: cantidad provisional conservada después de ocultar. `feed-*`: número separado de frase, incluyendo diez dígitos. WebP solo optimiza el archivo; no se retocó el contenido.

`og-1` a `og-5`: PNG creados por el generador real con fotos públicas del repositorio en un pedido fixture; sus cantidades y tienda son ejemplos. `*-cuadrado`: recorte central explícito para comprobar que las portadas, variante y total siguen dentro. `og-sin-fotos`: fallback de marca. No son capturas de una conversación real de WhatsApp ni de pedidos de producción.

Los JSON registran las comprobaciones específicas completadas; fallos iniciales y límites en [validación](../../validacion-catalogo-visibilidad-og.md). El estado READY del preview no demuestra Safari, Google real o WhatsApp.
