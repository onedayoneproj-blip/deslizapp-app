# Primera visita y selección persistida

Chromium/touch simulado a 360 y 390 px, fixture Demo local aislada del script `probar:selector-general`. Sin Supabase ni datos reales.

- `general-sin-preferencia-*`: primera visita sin selección guardada, General virtual activo en el menú.
- `de-todo-persistido-*`: selección física `general` restaurada tras recargar, con su producto.

No equivalen a Safari/PWA físico. Capturas anteriores del selector se conservan.
